# HackerRank - Arithmetic Operators

## Problem Description
Given two integers, `a` and `b`, print their sum, difference, and product on separate lines.

## Approach
1. Read the first integer `a`.
2. Read the second integer `b`.
3. Print `a + b`.
4. Print `a - b`.
5. Print `a * b`.

## Sample Input
```text
3
2
```

## Sample Output
```text
5
1
6
```

## Explanation
- Sum: `3 + 2 = 5`
- Difference: `3 - 2 = 1`
- Product: `3 * 2 = 6`
